# NightRider media and brand assets

Owner-approved branding artwork for use in print and digital marketing lives in `public/media/branding/`. The approved square image from 2026-10-30 shows the Talmadge Bridge with a striped orange/gold moon, dark emerald night, and upright cream/mint NR letters. The `nightrider-icon.webp` file is an optimized raster derivative of the exact user-provided image, not an independently generated replacement. The same source is used for Android launcher artwork in the companion repository.

For future driver recruiting business cards, flyers and posters, add separately named files to this folder and avoid claiming that NightRider is actively recruiting or offering transportation until the company is licensed and operating. Web icon consumers use `/media/branding/nightrider-icon.webp?v=barb-1` to bypass stale browser cache. The previous `nightrider-mark.svg` stays as a legacy reference until all uses are audited.
